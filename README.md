# CDMA Channel Simulation

## 📌 Description
This project simulates Code Division Multiple Access (CDMA):
- Multiple users transmit data simultaneously
- Walsh codes used for encoding
- Receiver decodes specific user's data

## ⚙️ Features
- Accepts 4 user data inputs
- Encodes using orthogonal codes
- Combines signals into one channel
- Decodes selected user's data
